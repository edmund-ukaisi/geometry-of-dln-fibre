\(\rho\) is chain-type, not antichain-type: it is the maximum size of a chain realized in one chart. Thus \(\rho\leq\operatorname{height}(P)\), with equality only if a longest chain is realized by some chart. Antichains are irrelevant—and Dilworth duality is wrong here—because incomparable profiles cannot occur together in any chart.

Unique minimum \(\widetilde T\) and maximum \(\widetilde T'\) do not imply that \(P\) is graded. For example,
\[
(0,0)<(2,0)<(2,2),\qquad
(0,0)<(0,1)<(0,2)<(2,2)
\]
has unique bounds but maximal chains of different lengths.

Consequently, \(\rho=a(\ell-a)+1\) requires additional structure: prove that every maximal \(\widetilde T\)-to-\(\widetilde T'\) chain has that length and that one is chart-realized. Coordinate-sum is a rank only if every cover increases the sum by exactly \(1\); sparse profile posets can have covers that jump several units. Otherwise a different recursively defined rank is needed.
