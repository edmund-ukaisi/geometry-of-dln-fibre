**(A)** FACT: `range δ⁰ ⊆ T_M Z_M` is automatic from `O_M ⊆ Z_M`. FACT: if `O_M` is open in `Z_M`, then `T_M O_M = T_M Z_M`; and in characteristic `0`, the algebraic-group theorem identifying the orbit as `G/Stab(M)` gives `T_M O_M = im dμ_M = range δ⁰`. INFERENCE: this is non-circular, but it is not “smoothness alone”; it imports orbit-stabilizer/tangent theory. Smoothness alone only gives `dim T_M Z_M = dim Z_M`, and using `dim Z_M = dim O_M = r` there would be circular unless `dim O_M = r` is proved independently.

**(B)** SUB-LIBRARY. FACT: the interval-subproduct minors define the same set as `Z_M`; by Nullstellensatz this gives `vanishingIdeal(Z_M) = radical(I_minors)`, not `I_minors` itself. FACT: L2a needs the stronger scheme-theoretic statement `I_minors = vanishingIdeal(Z_M)`, equivalently radicality/reducedness, and then primeness follows from irreducibility. FACT: for equioriented type A this is the quiver determinantal ideal theorem: orbit closures/quiver loci are scheme-theoretically cut out by these minors and are reduced/Cohen-Macaulay/prime, via Lakshmibai-Magyar/Zelevinsky or Knutson-Miller-Shimozono-type quiver determinantal theory. ([arxiv.org](https://arxiv.org/abs/alg-geom/9709018)) Mathlib v4.29 likely has matrix determinants/rank and commutative algebra infrastructure, but not this quiver determinantal ideal theory.

**(C)** FACT: given the minors, their Jacobian kernel at `M` is the first-order rank-preserving condition for every interval product: for each product `F`, the perturbation `H` satisfies `H(ker F) ⊆ im F`. FACT: in barcode/interval normal form this can be solved uniformly: the interval conditions kill exactly the Ext¹ directions, leaving precisely coboundaries `δ⁰(φ)`. INFERENCE: this is not per-orbit ad hoc, but it is bar/lace-parametrized uniform linear algebra; formalising it still needs a substantial local sub-library: tangent space of determinantal rank strata, differential of subproducts, barcode block decomposition, and the gauge-elimination/Voigt computation.

**(D)** SUB-LIBRARY. FACT: the clean dimension route is `dim O_M = dim G - dim Stab(M)`. Here `Stab(M)=Aut(M)` is the open unit locus in `End(M)`, so `dim Stab(M)=finrank End(M)=finrank ker δ⁰`; also `dim G=finrank C⁰`, hence `dim O_M=finrank C⁰ - finrank ker δ⁰ = finrank range δ⁰`. FACT: since `O_M` is locally closed, it is open dense in its closure, so `dim Z_M=dim O_M`. INFERENCE: this completely avoids Jacobians/minors for the dimension headline, but Mathlib v4.29 likely lacks the needed affine algebraic group action package: orbit-stabilizer dimension, stabilizer/orbit as varieties or schemes, locally-closed orbit dimension, and dimension preservation under closure.

**(E)** FACT: for the final equality, L2b only needs `finrank ker(Jacobian) = finrank range δ⁰`, not the subspace identity. FACT: the identity `ker(Jacobian)=range δ⁰` is stronger and useful because it proves the finrank equality immediately, but L4★ plus L2a already reduces the headline to a numerical comparison.

Verdict: the smallest non-circular route to `varietyDim(Z_M)=finrank(range δ⁰)` is orbit-stabilizer-dimension; determinantal-Jacobian is viable but heavier, and smoothness-only is insufficient. None is bounded in Mathlib v4.29; each real route pulls a missing sub-library.
