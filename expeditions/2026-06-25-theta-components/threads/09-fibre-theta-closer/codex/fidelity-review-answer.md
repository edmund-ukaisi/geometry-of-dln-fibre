Since `dim A` is the maximum of these dimensions, `ringKrullDim(A ⧸ p) = ringKrullDim A` selects exactly the top-dimensional components. It excludes lower-dimensional minimal primes, so it is the right invariant for the 6-vs-10 distinction. Non-equidimensionality is fine; catenarity is not needed for this definition. Concern only outside finite-type/finite-dimensional settings, where `∞` dimensions or missing finiteness for `ncard` can make the intended “top” count ambiguous.

Q2. **CONCERN.** Standard fact: localization keeps minimal primes exactly when they avoid the multiplicative set, and global no-drop prevents lower-dimensional components from being promoted. But global no-drop plus avoidance is not sufficient to keep every surviving top component top; that component’s own dimension can drop. Counterexample: `A = k[t]_(t) × k[u]_(u)`, `f = (t, 1)`. Both minimal primes are top and avoid `f`, and `dim A_f = dim A = 1`, but the first component localizes to a field, so top-component count drops from `2` to `1`. Clean sufficient condition: for every top minimal prime `p`, require `f ∉ p` and `dim((A ⧸ p)_f) = dim(A ⧸ p)`, together with `dim A_f = dim A` or an implication thereof. For finite-type `k`-domains this per-prime no-drop is standard, so the rung passes if Lean really proves/uses it.
