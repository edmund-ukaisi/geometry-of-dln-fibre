## New module + signatures (all ns `MvPolynomial`, `variable {R : Type*} [CommRing R] {ι : Type*}`)

`DLNFibre/Core/MvPolynomial/GraphIdeal.lean` (109 LoC):

```
noncomputable def graphIdeal (c : ι → R) : Ideal (MvPolynomial ι R) :=
  Ideal.span (Set.range fun i ↦ X i - C (c i))

theorem sub_C_mem_ker_aeval (c : ι → R) (i : ι) :
    X i - C (c i) ∈ RingHom.ker (aeval (R := R) c).toRingHom

theorem sub_C_aeval_mem_graphIdeal (c : ι → R) (p : MvPolynomial ι R) :
    p - C (aeval c p) ∈ graphIdeal c

theorem ker_aeval_eq_graphIdeal (c : ι → R) :       -- THE HEADLINE
    RingHom.ker (aeval (R := R) c).toRingHom = graphIdeal c

theorem aeval_surjective (c : ι → R) :
    Function.Surjective (aeval (R := R) c)

noncomputable def graphIdealQuotientEquiv (c : ι → R) :
    (MvPolynomial ι R ⧸ graphIdeal c) ≃ₐ[R] R

theorem graphIdeal_isPrime [IsDomain R] (c : ι → R) :   -- prime over a domain
    (graphIdeal c).IsPrime
```

**English gloss.** For an evaluation point `c : ι → R` (any index type, any commutative base ring),
the kernel of `aeval c : MvPolynomial ι R →ₐ[R] R` is the **graph ideal** generated by the shifted
coordinates `X i − C (c i)`. Hence the quotient by the graph ideal is `R` itself
(`graphIdealQuotientEquiv`, the elimination), and the graph ideal is prime when `R` is a domain.

**Minimal hypotheses (confirmed).** All decls need only `[CommRing R]` and an arbitrary `ι` — *no*
`Finite`/`Fintype`/`DecidableEq` on `ι`. `graphIdeal_isPrime` adds `[IsDomain R]` (needed: over a
non-domain `aeval c` lands in a non-domain so the kernel need not be prime). The finiteness-free
proof of the headline is the load-bearing generality: the translation identity
`sub_C_aeval_mem_graphIdeal` is proved by `MvPolynomial.induction_on`, dodging the
`Finite.induction_empty_option` route and its universe friction.
