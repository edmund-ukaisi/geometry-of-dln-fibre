# Reproduction - A2 canonical product-difference coefficient-field continuity

Date: 2026-06-24.

Status: pen-and-paper reproduction before Lean implementation.

## Question

Aoyagi's product-reduction step rewrites the product difference near a rank
`r` base point into a cleaned block family generated by

```text
Ctop - I,  F2,  F3,  D.
```

The Lean development has already proved the algebraic entry-ideal equality
with deterministic suffix-state fields

```text
F2 = -S.B,
F3 = lowerLeftBlock S.L,
Ctop = S.Ctop,
D = S.D.
```

It has also proved that the deterministic suffix-state fields
`S.L`, `S.B`, `S.Ctop`, and `S.D` vary continuously in fixed endpoint bases
under the recursive determinant-chart hypotheses.  The present slice
reproduces the missing local-function handoff: the actual four coefficient
fields appearing in the cleaned product-difference ideal are continuous at the
base parameter, and at the base chain those centered coefficient fields vanish.

## Source Anchor

Aoyagi Theorem 3 and the paragraph following it, PDF pp. 11-13, use full-rank
block charts to separate regular coordinates from the reduced singular
product.  The source-level calculation is local: the matrices `P`, `Q`, and
block factors are functions of the entries near the base point on determinant
charts.  This slice only formalises the elementary continuity part of that
local dependence for the deterministic fixed-base fields already constructed
in Lean.

The source does not by itself give an analytic germ-ideal transport theorem or
normal-crossing certificate.  Those remain outside this slice.

## Reproduction

Fix a continuous reversed-edge family `Cedge : alpha -> edges`, with base
parameter `x0`.  In endpoint bases fixed from the base chain `B`, define

```text
E(x,p) = matrix of Cedge(x,p) in the fixed endpoint bases.
S(x)   = suffixState E(x) (last N) 0.
```

The existing fixed-base suffix-state theorem gives, under recursive determinant
chart hypotheses at `x0`,

```text
IsUnit (S(x0).Ctop.det),
ContinuousAt (fun x => S(x).L)    x0,
ContinuousAt (fun x => S(x).B)    x0,
ContinuousAt (fun x => S(x).Ctop) x0,
ContinuousAt (fun x => S(x).D)    x0.
```

The coefficient fields in the canonical product-difference ideal are obtained
from these four fields by continuous operations:

1. `Ctop - I` is the difference of the continuous field `S.Ctop` and the
   constant identity matrix.
2. `-S.B` is negation of the continuous field `S.B`.
3. `lowerLeftBlock S.L` is a fixed submatrix projection of the continuous
   matrix field `S.L`.
4. `S.D` is already one of the suffix-state fields.

Therefore the four canonical coefficient fields are continuous at `x0`.

At the self-base parameter, where `Cedge x0` is the original reversed chain
`B`, the recursive determinant-chart hypotheses are already supplied by the
existing self-base determinant-chart theorem.  Hence the same conclusion has a
source-facing self-base corollary with assumptions only `ContinuousAt Cedge x0`
and `Cedge x0 = B`.

## Basepoint Centering

At the self-base parameter, the fixed endpoint bases were chosen from the base
chain `B`.  The base total product is therefore the rank-model block

```text
T0 = fromBlocks I 0 0 0.
```

The deterministic suffix-state block-diagonal invariant gives

```text
S.L * T0 * fromBlocks I (-S.B) 0 I = fromBlocks S.Ctop 0 0 S.D.
```

The suffix-state lower multiplier is lower unitriangular:

```text
S.L = fromBlocks I 0 F3 I
```

with `F3 = lowerLeftBlock S.L`.  Multiplying the left side gives

```text
fromBlocks I (-S.B) F3 (F3 * (-S.B)).
```

Comparing block entries with the right side gives

```text
S.Ctop = I,
-S.B = 0,
F3 = 0,
S.D = 0.
```

Thus the four canonical generator fields are centered at the base point:

```text
S.Ctop - I = 0,
-S.B = 0,
lowerLeftBlock S.L = 0,
S.D = 0.
```

## Lean Shape

Add two endpoint fixed-base theorems in
`lean/DLNFibre/DLN/Aoyagi/ProductReductionEntryIdealBoundary.lean`:

```text
paperEndpointFixedBaseContinuousEdges_productDifferenceCoefficientFields_continuousAt

paperEndpointFixedBaseContinuousEdges_selfBase_productDifferenceCoefficientFields_continuousAt

paperEndpointFixedBaseContinuousEdges_selfBase_productDifferenceCoefficientFields_centered_continuousAt
```

Both should return:

```text
let E x p := fixed-base matrix of Cedge x p
let S x := ChartLocalSuffixState.suffixState (E x) (Fin.last N) 0 ...
IsUnit ((S x0).Ctop.det) ∧
ContinuousAt (fun x => (S x).Ctop - 1) x0 ∧
ContinuousAt (fun x => -(S x).B) x0 ∧
ContinuousAt (fun x => lowerLeftBlock (S x).L) x0 ∧
ContinuousAt (fun x => (S x).D) x0
```

The first theorem should take the explicit recursive determinant-chart
hypotheses.  The second should derive those hypotheses from the existing
self-base chart theorem.

The centered self-base theorem should additionally return:

```text
(S x0).Ctop - 1 = 0,
-(S x0).B = 0,
lowerLeftBlock (S x0).L = 0,
(S x0).D = 0.
```

## Kill Conditions

- If the theorem needs analytic differentiability or analytic unit control,
  the statement is too strong.
- If the theorem claims exact-rank/source-rank openness, chart coverage, or
  ideal-germ transport, it is over-scoped.
- If the theorem packages the algebraic ideal equality again without adding
  continuity of the concrete fields, it is wrapper churn.
- If the centered theorem identifies `S.D` with a raw lower-right product
  instead of only proving the basepoint value `S.D = 0`, it is over-scoped.

## Nonclaims

- No analytic regularity or smoothness theorem.
- No exact-rank openness or source-rank neighborhood construction.
- No chart coverage or source production.
- No analytic ideal/germ transport.
- No regular-suspension certificate.
- No normal crossings, pole order, or RLCT extraction.
