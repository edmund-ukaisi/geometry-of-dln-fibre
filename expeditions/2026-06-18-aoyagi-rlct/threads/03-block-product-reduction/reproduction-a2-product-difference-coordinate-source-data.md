## Source Anchor

Aoyagi PDF p. 13 displays the product-difference block after Theorem 3 with
the signed regular blocks and the lower-right quadratic correction:

```text
C1 - Er,   -F2,   -F3,   prod_s C^(s) - F3 F2.
```

The earlier A2 entry-ideal boundary proves the elementary cleanup from this
literal displayed block to the same scalar entry ideal generated by

```text
C1 - Er,   F2,   F3,   prod_s C^(s),
```

using sign-invariance of entry ideals and the fact that entries of `F3 F2`
lie in the ideal generated by entries of `F2` and `F3`.  The present slice
formalizes this cleaned ideal-level four-family as one scalar coordinate
index.  In the fixed-base Lean suffix-state notation the cleaned families are

```text
S.Ctop - 1,   -S.B,   lowerLeftBlock S.L,   S.D.
```

The first three are the regular-coordinate families; the last is the reduced
residual product block.

## Calculation

Define one scalar coordinate index for the cleaned p. 13 product-difference
ideal-level family by adjoining the regular and residual scalar-coordinate
indices:

```text
AoyagiProductDifferenceCoordinateIndex(iota, mu, nu)
  =
AoyagiRegularBlockCoordinateIndex(iota, mu, nu)
  +
AoyagiResidualBlockCoordinateIndex(mu, nu).
```

Its scalar value sends regular coordinates to the entries of

```text
X, F2, F3
```

and residual coordinates to the entries of

```text
D.
```

Therefore its generated ideal is exactly

```text
regularBlockEntryIdeal X F2 F3 + matrixEntryIdeal D
  =
fourMatrixEntryIdeal X F2 F3 D.
```

For the fixed-base p. 13 source package this gives the source-stratum guarded
identity

```text
matrixEntryIdeal(productDifference)
  =
AoyagiProductDifferenceCoordinateIndex.entryIdeal
  (S.Ctop - 1) (-S.B) (lowerLeftBlock S.L) S.D.
```

Centered continuity is componentwise: the already reproduced regular and
residual centered-continuity packages combine by cases on the sum index.

The finite endpoint count is

```text
r*r + r*(H(L+1)-r) + (H(1)-r)*r + (H(1)-r)*(H(L+1)-r)
  =
H(1) * H(L+1),
```

using the endpoint rank-width bounds `r <= H(1)` and `r <= H(L+1)`.
