# Reproduction - A2 one-step determinant-chart coordinate equivalence

Date: 2026-06-24.

Status: pen-and-paper reproduced; xhigh review passed; formalised in Lean.

## Source Anchor

Aoyagi PDF pp. 11-13 performs the product reduction by repeatedly applying
Lemma 2 on a determinant chart for a full-rank square block.  In one step the
raw variables have block form

```text
[ C1  0 ] [ A1  A2 ]
[ 0   D ] [ A3  A4 ].
```

The determinant chart hypotheses are

```text
det(C1) is a unit,
det(A1) is a unit.
```

The product-reduction step uses the Schur-complement change of variables

```text
Ctop = C1 A1,
F2   = - A1^{-1} A2,
F3   = F3_old - D A3 (C1 A1)^{-1},
C    = A4 - A3 A1^{-1} A2,
```

with `D`, `A1`, and `A3` kept as passive chart variables.  No inverse of `D`
is used.

## Domains

Let the raw coordinate object be

```text
x = (C1, D, F3_old, A1, A2, A3, A4).
```

Its determinant-chart domain is

```text
RawChart = { x | IsUnit det(C1) and IsUnit det(A1) }.
```

Let the chart coordinate object be

```text
y = (Ctop, D, A1, A3, F2, F3, C).
```

Its determinant-chart domain is

```text
ChartDomain = { y | IsUnit det(Ctop) and IsUnit det(A1) }.
```

The forward map sends `RawChart` to `ChartDomain` because

```text
det(Ctop) = det(C1 A1) = det(C1) det(A1),
```

and both factors are units.  The `A1` determinant condition is copied.

The inverse map sends `ChartDomain` to `RawChart` by

```text
C1     = Ctop A1^{-1},
D      = D,
F3_old = F3 + D A3 Ctop^{-1},
A1     = A1,
A2     = - A1 F2,
A3     = A3,
A4     = C - A3 F2.
```

The raw `C1` determinant is a unit because

```text
det(C1) = det(Ctop) det(A1^{-1}),
```

and `det(A1^{-1})` is a unit on the `A1` determinant chart.

## Inverse Checks

Starting from raw variables, the inverse of the forward chart variables gives

```text
C1' = (C1 A1) A1^{-1} = C1,
D' = D,
A1' = A1,
A3' = A3,
A2' = -A1(-A1^{-1}A2) = A2,
A4' = (A4 - A3 A1^{-1} A2) - A3(-A1^{-1}A2) = A4.
```

For the old lower-left field,

```text
F3_old'
  = (F3_old - D A3 (C1 A1)^{-1}) + D A3 (C1 A1)^{-1}
  = F3_old.
```

Only the `A1` inverse and the determinant-unit status of `C1 A1` are used.

Starting from chart variables, the forward map of the inverse raw variables
gives

```text
Ctop' = (Ctop A1^{-1}) A1 = Ctop,
D' = D,
A1' = A1,
A3' = A3,
F2' = -A1^{-1}(-A1F2) = F2,
C' = (C - A3F2) - A3A1^{-1}(-A1F2) = C.
```

For the chart lower-left field,

```text
F3'
  = (F3 + D A3 Ctop^{-1})
      - D A3 ((Ctop A1^{-1}) A1)^{-1}
  = F3 + D A3 Ctop^{-1} - D A3 Ctop^{-1}
  = F3.
```

The target determinant chart includes `IsUnit det(Ctop)` so that `Ctop^{-1}`
is a regular expression on the chart.  The algebraic cancellation of `F2` and
`C` uses the `A1` chart condition.

## Continuity and Homeomorphism Level

The finite matrix spaces carry the product topology from the entries.  The raw
and chart coordinate structures are finite products of these matrix spaces, so
the intended topology is the product topology generated by field projections.

On determinant-unit loci, matrix inversion is continuous:

```text
ContinuousAt (fun M => M^{-1}) M0
```

whenever `IsUnit det(M0)`.  Matrix multiplication, addition, negation,
subtraction, and blockwise projections are continuous.  Therefore:

- the forward map is continuous on `RawChart`;
- the inverse map is continuous on `ChartDomain`;
- together with the inverse identities above, they define a homeomorphism
  between the two determinant-chart subtypes.

This is a finite topological coordinate equivalence.  It is a stronger and more
honest statement than centered continuity of selected scalar coordinate
families, but it is still below analytic regularity.
