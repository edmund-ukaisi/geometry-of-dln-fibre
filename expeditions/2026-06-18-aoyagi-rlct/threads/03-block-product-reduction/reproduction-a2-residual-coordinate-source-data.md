## Source Anchor

Aoyagi PDF p. 13 applies Theorem 3 to the product difference and displays the
four block generator families

```text
C1 - Er,   F2,   F3,   prod_s C^(s) - F3 F2.
```

The first three families are the regular variables counted by the displayed
regular term.  In the fixed-base Lean convention these are

```text
S.Ctop - 1,   -S.B,   lowerLeftBlock S.L.
```

The remaining family is the reduced residual block.  After the existing ideal
cleanup, its matrix-entry ideal is represented by `matrixEntryIdeal S.D`, where
`S.D` is the deterministic residual product field of the fixed-base suffix
state.

## Calculation

Let `mu` be the row/left residual endpoint index and `nu` the column/right
residual endpoint index.  The scalar residual-coordinate index is simply

```text
mu x nu.
```

For a residual block

```text
D : Matrix mu nu R,
```

the scalar coordinate value is

```text
(i,j) |-> D i j.
```

Therefore the ideal generated by all scalar residual coordinates is exactly the
matrix-entry ideal:

```text
span { D i j : i in mu, j in nu } = matrixEntryIdeal D.
```

This is only the residual side of the already-proved regular/residual split

```text
matrixEntryIdeal(productDifference)
  =
regularCoordinateIdeal(S.Ctop - 1, -S.B, lowerLeftBlock S.L)
  + matrixEntryIdeal S.D.
```

The canonical local product-difference certificate already proves the
basepoint centering and continuity of `S.D`.  Projecting componentwise gives,
for every scalar residual coordinate `(i,j)`,

```text
(S x0).D i j = 0,
ContinuousAt (fun x => (S x).D i j) x0.
```

With the endpoint dimension convention

```text
H(k+1) = finrank(W k)
```

and base product rank `r`, the endpoint complement counts give

```text
|mu| = H(1) - r,
|nu| = H(N+1) - r.
```

Hence the scalar residual-coordinate count is

```text
|mu x nu| = (H(1)-r) * (H(N+1)-r).
```

This count is not the regular-variable shift.  It records the number of scalar
entries in the reduced residual block.
