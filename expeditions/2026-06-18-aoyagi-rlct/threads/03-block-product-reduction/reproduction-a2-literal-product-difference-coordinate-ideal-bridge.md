Status: reproduced before Lean naming bridge.

## Source Anchor

Aoyagi PDF p. 13 displays the product-difference block with signs and the
lower-right correction

```text
[C1 - Er, -F2; -F3, D - F3 F2].
```

The existing coordinate-source data package uses the cleaned scalar coordinate

```text
C1 - Er, F2, F3, D.
```

The bridge in this slice names the elementary equality between the literal
displayed block's matrix-entry ideal and the scalar coordinate-index ideal for
the cleaned family.

## Calculation

For arbitrary finite top index `iota` and block matrices

```text
X  : Matrix iota iota R
F2 : Matrix iota nu R
F3 : Matrix mu iota R
D  : Matrix mu nu R,
```

the earlier entry-ideal cleanup proves

```text
matrixEntryIdeal (fromBlocks X (-F2) (-F3) (D - F3*F2))
  =
fourMatrixEntryIdeal X F2 F3 D.
```

The signs do not change the ideals generated by `F2` and `F3`, and the entries
of `F3*F2` lie in the ideal generated by entries of `F2` and `F3`.

The product-difference coordinate-index theorem proves

```text
AoyagiProductDifferenceCoordinateIndex.entryIdeal X F2 F3 D
  =
fourMatrixEntryIdeal X F2 F3 D.
```

Composing these equalities gives the desired bridge:

```text
matrixEntryIdeal (fromBlocks X (-F2) (-F3) (D - F3*F2))
  =
AoyagiProductDifferenceCoordinateIndex.entryIdeal X F2 F3 D.
```

The only finiteness needed by the correction term is the summation index in
`F3*F2`, namely `Fintype iota`.
