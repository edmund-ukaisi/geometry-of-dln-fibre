# Regular-suspension plan after Theorem 3

Status: plan, not yet a reproduction certificate.

Source used: Aoyagi 2023 PDF p. 13, plus the A2 repair reports. This plan is
Aoyagi-only and does not use the quiver paper.

## Problem

After Theorem 3, Aoyagi writes the product-difference block ideal in variables
`C1 - Er`, `F2`, `F3`, and the reduced product `prod C^(s)`, then states the
RLCT contribution

```text
(-r^2 + r(H^(1) + H^(L+1))) / 2.
```

This is the contribution of the regular variables

```text
C1 - Er        size r x r,
F2             size r x (H^(L+1)-r),
F3             size (H^(1)-r) x r.
```

The count is

```text
c = r^2 + r(H^(L+1)-r) + r(H^(1)-r)
  = -r^2 + r(H^(1) + H^(L+1)).
```

The intended shift is `c / 2`.

## Trap

Do not model this by naively appending variables with exponent ratio `1/2` to
the reduced normal-crossing data. A sum such as

```text
x^2 + y^(2a)
```

has RLCT contributions from a product-type normal-crossing resolution of the
sum, not from taking the minimum of the raw coordinate ratios. The additive
shift is a statement about a constructed normal-crossing certificate or about a
separate analytic additivity theorem. The latter is not currently allowed as a
second citation.

## Target certificate shape

Given a reduced normal-crossing certificate for the reduced product ideal
`<prod C^(s)>`, construct a full certificate for

```text
<C1 - Er, F2, F3, prod C^(s)>
```

or for the algebraically equivalent family obtained from the block
product-difference after removing `F3 F2`.

The finite certificate should make the regular variables a genuine suspension:

- the regular variables contribute `c / 2` to `lambda`;
- they do not change the pole order once the reduced chart realizes the global
  minimum;
- the chart family still covers the relevant local neighborhood.

## Elementary prerequisites

Prove in Lean before using this plan:

1. `matrixEntryIdeal` for a matrix over a commutative ring.
2. Left/right multiplication by determinant-unit square matrices preserves the
   matrix-entry ideal.
3. Entries of `F3 * F2` lie in the ideal generated by entries of `F2` and
   `F3`.
4. Therefore

```text
<entries X, entries F2, entries F3, entries (D - F3 F2)>
  = <entries X, entries F2, entries F3, entries D>.
```

Here `X` will later stand for `C1 - Er`, and `D` for `prod C^(s)`.

## Finite certificate-arithmetic socket

The finite exponent-array socket now exists in
`lean/DLNFibre/DLN/Aoyagi/NormalCrossingInterface.lean` under the narrower
name

```text
jacobianPriorLossShift
```

It keeps the loss exponents `k` fixed and replaces the Jacobian/prior exponents
`h` by `h + c*k`.  Lean proves, for active coordinates, that every ratio shifts
by `c/2`, that the finite minimum shifts by `c/2`, and that the
minimum-coordinate chart counts and finite order are preserved:

```text
ratioAt_jacobianPriorLossShift_of_mem_activePairs
exponentMinimum_jacobianPriorLossShift
coordsInChartAtRatio_jacobianPriorLossShift
countInChartAtRatio_jacobianPriorLossShift
minCoordsInChart_jacobianPriorLossShift
minCountInChart_jacobianPriorLossShift
exponentOrder_jacobianPriorLossShift
```

This is only combinatorial certificate arithmetic.  It is not the
regular-suspension chart construction, and it does not justify applying the
normal-crossing extraction theorem to a reduced certificate and then adding
`c/2`.  The final single extraction citation must still be applied to the full
certificate after A4/A5/A2 provide the chart and source-production data.

## Blockers

- A4 reduced certificate is still blocked by width notation, missing pivot
  charts, invariant recurrence, regularity/divisibility, and termination.
- A5 arithmetic is still blocked by endpoint and order-count gaps.
- Transport back to the original product-difference loss still needs
  certificate-level generator transport or a proved elementary same-generator
  construction; Aoyagi Lemma 1 is not available as a separate citation.
