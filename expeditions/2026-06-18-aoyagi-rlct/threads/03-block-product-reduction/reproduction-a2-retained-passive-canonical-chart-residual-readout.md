# A2 retained-passive canonical chart residual readout

Status: Lean proved; focused/full builds, local gates, and xhigh review passed.

## Claim

For the canonical retained-passive p.13 source chart, the residual coordinate
expression appearing in the chart-side hypotheses is not an opaque source-map
composite.  On the determinant chart it is exactly the finite residual product
of the raw edge matrices, and equivalently the residual-factor product of the
stored retained-passive `C` blocks.

With

```text
rho = Fin (finrank R U0)
kappa' = throughSubspaceEndpointComplementIndex (reverseVertex W) (reverseEdge W B) U0
EFam = forall p : Fin (M+1),
  reverseVertex W p.castSucc ->L[R] reverseVertex W p.succ
sourceChart y =
  paperEndpointFixedBaseRetainedPassiveP13SourceEdgeFamilyOfData W B U0 hU0
    (ofTopologyTuple (topologyTupleEdgeRawOrderInverse y))
```

and `z` in the retained-passive determinant chart, the chart-side residual
readout

```text
paperEndpointFixedBaseResidualBlockCoordinateMap W B U0 hU0 id
  (sourceChart (topologyTupleEdgeRawOrder z))
```

is the coordinate readout of

```text
residualProduct (topologyTupleEdgeMatrix z) last 0,
```

and also the coordinate readout of

```text
residualFactorProduct (ofTopologyTuple z).C last 0.
```

## Source calculation

Aoyagi's p.13 calculation follows Theorem 3.  After normalising the target
product to

```text
[ I_r  0 ]
[  0   0 ],
```

the triangular regular multipliers give

```text
P1 (prod_s A^(s)) P2 =
[ C1       0        ]
[ 0    prod_s C^(s)]
```

and hence

```text
P1 (prod_s A^(s) - prod_s A_*^(s)) P2 =
[ C1 - I_r          -F2        ]
[ -F3       prod_s C^(s) - F3F2].
```

The regular variables are `C1 - I_r`, `F2`, and `F3`.  Since the entries of
`F3F2` lie in the ideal generated by entries of `F2` and `F3`, the residual
singular part is represented by the lower-right product `prod_s C^(s)`.

The retained-passive chart formalisation expresses this lower-right product as
the deterministic suffix residual product.  The source readback of a
determinant-chart retained-passive datum recovers that datum, so this suffix
residual product is the residual-factor product of the stored `C` blocks.

## Lean reproduction

Let

```text

```

If `z` is in `topologyTupleDetChartSet`, then
`mapsTo_topologyTupleEdgeRawOrder_detChartSet_rawOrderSourceRecursiveDetChartSet`
places `y` in the raw-order source-recursive determinant chart.  The canonical
source-chart realisation theorem gives

```text

  (fun p => sourceChart y p)
= edgeFamilyOfRawOrderTuple y.
```

For `y = topologyTupleEdgeRawOrder z`,
`edgeFamilyOfRawOrderTuple_topologyTupleEdgeRawOrder` rewrites this edge family
as

```text

```

The fixed-base residual map theorem then gives the first readout:

```text
paperEndpointFixedBaseResidualBlockCoordinateMap id (sourceChart y)
= value (residualProduct (topologyTupleEdgeMatrix z) last 0).
```

For the stronger retained-passive coordinate form, use the existing source
readback theorem:

```text
paperEndpointFixedBaseResidualBlockCoordinateMap_eq_sourceReadback_residualFactorProduct
```

to read the same residual map as

```text
value (residualFactorProduct (sourceReadback (topologyTupleEdgeMatrix z)).C last 0).
```

The determinant-chart hypothesis is exactly

```text

```

Since `topologyTupleEdgeMatrix z` is definitionally `(ofTopologyTuple z).edgeMatrix`,
`sourceReadback_edgeMatrix_eq` rewrites

```text

```

This gives the final residual-factor product over `(ofTopologyTuple z).C`.

## Boundary

This checkpoint identifies the chart-side residual expression.  It does not
prove residual zero-locus nullity, chart-side a.e. residual positivity, finite
negative-power integrability, a monomial lower bound, source-density
identification, original-prior transport, normal crossings, pole order, or
RLCT.

## Kill conditions

- The determinant-chart hypothesis is missing; source readback need not recover
  arbitrary retained-passive data outside that chart.
- The statement claims zero-locus or integrability consequences rather than
  only a pointwise residual readout.
- The right side is treated as a selected-entry or signed-box density statement;
  it is only the product of compatible stored residual factors.
- The result is used to remove chart-side residual positivity or finite
  integral hypotheses without a separate zero-locus, monomial, or
  normal-crossing argument.
