# A2 product-difference entry-ideal boundary reproduction

Date: 2026-06-23.

Source context: Aoyagi 2023 preprint, p. 13, immediately after the product
reduction of Theorem 3.  This note uses only the elementary block algebra
already reproduced in `reproduction-a2-block-product-difference-algebra.md`.
It does not use the quiver paper or quiver Lean development.

## Setup

Work over a commutative ring.  Let the rank block have index `i`, the final
left residual row block have index `m`, and the final right residual column
block have index `n`.  Let

```text
T : Matrix (i + m) (i + n)
F2 : Matrix i n
F3 : Matrix m i
Ctop : Matrix i i
D : Matrix m n.
```

Write

```text
L = [ I  0 ]
    [ F3 I ],

R = [ I F2 ]
    [ 0 I  ],

T0 = [ I 0 ]
     [ 0 0 ].
```

The already-formalized endpoint triangular product-reduction statement supplies

```text
L T R = [ Ctop 0 ]
        [ 0    D ].
```

In the source-boundary wrapper, `T` is the fixed-base endpoint product matrix
of the nearby chain, `T0` is the fixed-base endpoint matrix of the base product,
and `D` is the deterministic residual product exposed by the endpoint
certificate.  We do not identify `D` with a raw product of original lower-right
blocks.

## Product-difference block calculation

By distributivity and direct block multiplication,

```text
L (T - T0) R
  = L T R - L T0 R
  = [ Ctop 0 ] - [ I F2   ]
    [ 0    D ]   [ F3 F3F2]
  = [ Ctop - I  -F2     ]
    [ -F3       D - F3F2].
```

This is exactly the finite block identity already proved in Lean as
`triangularBlockProductDifference_fromBlocks_indexed`.

## Entry-ideal consequence

Let `I(M)` denote the ideal generated by all entries of a finite matrix `M`.
If the determinants of `L` and `R` are units, then determinant-unit left and
right multiplication preserve `I(-)`, so

```text
I(T - T0) = I(L (T - T0) R).
```

The entries of a block matrix generate the supremum of the entry ideals of its
four blocks.  Sign changes do not change an entry ideal.  Therefore

```text
I(T - T0)
  = < entries(Ctop - I), entries(F2), entries(F3),
      entries(D - F3F2) >.
```

The product term `F3F2` is redundant modulo the entries of `F2` and `F3`: each
entry of `F3F2` is a finite sum of products of an entry of `F3` with an entry of
`F2`.  Hence the previous ideal equals

```text
< entries(Ctop - I), entries(F2), entries(F3), entries(D) >.
```

This is the scalar matrix-entry-ideal handoff wanted at the A2 boundary.

## Boundary

This proves only an algebraic equality of scalar entry ideals attached to the
fixed-base endpoint matrices.  It is not an equality of analytic germ ideals,
does not assert exact-rank strata are open, does not prove regular-suspension
RLCT additivity, does not construct normal-crossing charts, and does not prove
pole order or RLCT.
