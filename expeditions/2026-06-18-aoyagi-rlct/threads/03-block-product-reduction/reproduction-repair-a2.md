# A2 repair report - Aoyagi Theorem 3 product reduction

Source used: Aoyagi 2023 PDF only, especially Lemma 1 on p. 5 and
Lemma 2/Theorem 3 on pp. 10-13.

Checker/scout: xhigh scout `Erdos`; read-only, no files edited.

## Verdict

The algebraic induction in Theorem 3 is repairable, but only as a chart-local
block-matrix theorem with explicit basis and invertibility hypotheses. The
source's normalization of the true product is made "by Lemma 1"; that is
analytic/RLCT ideal-generator input, not an elementary algebra step. It must not
be hidden inside the A2 Lean algebra theorem.

## Source-faithful algebraic statement

Let `A^(s)` be real matrices of size `H^(s) x H^(s+1)` for
`s = 1,...,L`, and let `r` be the rank of the true product
`A*^(1)...A*^(L)`. Set `M^(s) = H^(s)-r`.

### Matrix dimensions/ranks

- `L >= 1`.
- `0 <= r <= H^(s)` for every `s = 1,...,L+1`.
- Source context: `A^(s)` is near `A*^(s)` and has/source-denotes rank
  `r^(s)`, with `r^(s) >= r`.
- Lemma 2 rank consequence: if a layer matrix has rank `r^(s)` and the selected
  `r x r` corner is invertible, then the Schur complement `C^(s)` has rank
  `r^(s)-r`.
- Theorem 3 itself only needs the invertible-corner chart for the block
  identities; exact layer ranks are only needed for residual-rank conclusions.

### Open-chart/invertible-block choices

The theorem must be stated on a chart where all inverses used in the proof
exist:

- Base chart: the top-left `r x r` block `A_1^(1)` of `A^(1)` is invertible.
- Inductive chart: after the prefix right multiplier `Q_2'` has been built,
  define `A'^(S+1) = (Q_2')^{-1} A^(S+1)`. The top-left `r x r` block `A_1'`
  of `A'^(S+1)` must be invertible.
- Aoyagi phrases this as "we can assume `C_1' A_1'` is regular." Since `C_1'`
  is already regular, this is equivalent to `A_1'` being regular, but Lean
  should not leave this implicit.

### Basis/normalization assumptions

Aoyagi writes, after invoking Lemma 1, that the true product may be assumed to
be

```text
[ E_r  0
  0    0 ].
```

For the algebraic induction, product normalization alone is not enough. One also
needs a through-layer basis choice: for each intermediate space, the first `r`
coordinates must follow an `r`-dimensional subspace transported isomorphically
through the true factors. Equivalently, after constant basis changes, the true
factors should have invertible top-left `r x r` blocks, and preferably
lower-left zero blocks, so the required charts contain the base point.

This basis lemma is elementary linear algebra, but it is not written explicitly
in Aoyagi's Theorem 3 proof.

### Analytic/RLCT assumptions not to hide

Aoyagi Lemma 1 is analytic: it compares/equates log canonical thresholds for
ideals generated by analytic functions. Therefore:

- target-product normalization "by Lemma 1" is not part of the elementary
  algebra proof;
- invariance under local analytic coordinate changes is not part of the block
  identity;
- replacing generators after multiplying by variable-dependent regular matrices
  `P1`, `P2` is analytic/ideal-germ input;
- adding `(-r^2 + r(H^(1)+H^(L+1)))/2` regular coordinates to the RLCT is
  analytic input.

Under the single-citation rule, these must be folded into the analytic interface
or avoided, not cited silently inside A2.

## Algebraic induction

### Base case

Partition

```text
A^(1) = [ A_1^(1)  A_2^(1)
          A_3^(1)  A_4^(1) ],
```

with `A_1^(1)` invertible. Apply A1/Lemma 2:

```text
Q_1^(1) A^(1) Q_2^(1)
  = [ A_1^(1)  0
      0        C^(1) ],
```

where

```text
C^(1) = A_4^(1) - A_3^(1) (A_1^(1))^{-1} A_2^(1).
```

If `rank A^(1)=r^(1)`, then `rank C^(1)=r^(1)-r`.

### Inductive invariant

After `S` layers, maintain triangular regular matrices

```text
Q_1' = [ E_r  0
         F_3' E_{H^(1)-r} ],

Q_2' = [ E_r  F_2'
         0    E_{H^(S+1)-r} ],
```

such that

```text
Q_1' (A^(1)...A^(S)) Q_2'
  = [ C_1'  0
      0     D_S ],
```

where

```text
C_1' is invertible,
D_S = C^(1)...C^(S),
C^(s) has size M^(s) x M^(s+1).
```

The next chart hypothesis is that the top-left block `A_1'` of

```text
A'^(S+1) = (Q_2')^{-1} A^(S+1)
         = [ A_1' A_2'
             A_3' A_4' ]
```

is invertible.

### Induction step

Compute

```text
Q_1' (A^(1)...A^(S)) A^(S+1)
= [ C_1' A_1'  C_1' A_2'
    D_S A_3'   D_S A_4' ].
```

Since `C_1'` and `A_1'` are invertible, define

```text
Q_1'' =
[ E_r  0
  -D_S A_3' (C_1' A_1')^{-1}  E_{H^(1)-r} ].
```

Then the lower-left block is killed, and the lower-right block becomes

```text
D_S A_4' - D_S A_3' (C_1' A_1')^{-1} C_1' A_2'
= D_S (A_4' - A_3' (A_1')^{-1} A_2').
```

Set

```text
C^(S+1) = A_4' - A_3' (A_1')^{-1} A_2'.
```

Then right-eliminate with

```text
Q_2'' =
[ E_r  -(A_1')^{-1} A_2'
  0     E_{H^(S+2)-r} ].
```

This gives

```text
Q_1'' Q_1' (A^(1)...A^(S+1)) Q_2''
= [ C_1' A_1'  0
    0           D_S C^(S+1) ].
```

The new invariant has

```text
C_1'' = C_1' A_1',
F_3'' = F_3' - D_S A_3' (C_1' A_1')^{-1},
F_2'' = -(A_1')^{-1} A_2'.
```

Note: the old right multiplier is absorbed into `A'^(S+1)`; the new right
multiplier is `Q_2''`, not a product with the old one.

## Boundary cases

- `r=0`: all top-left blocks are `0 x 0`; the theorem reduces to the unreduced
  product. Determinant/invertibility conditions are vacuous in the usual
  empty-matrix sense.
- `r=H^(1)`: the lower row block has size zero; `F_3` and the residual product
  have zero rows.
- `r=H^(L+1)`: the lower column block has size zero; `F_2` and the residual
  product have zero columns.
- Intermediate `H^(s)=r`: residual dimension `M^(s)=0`; adjacent `C` matrices
  have zero columns/rows, and products must be interpreted with empty matrices.
- Lean targets should use `Fin 0`-compatible matrix statements and avoid
  nonempty pivot assumptions.
