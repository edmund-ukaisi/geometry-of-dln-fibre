# A4 Case 2 Displayed Source-Chart Principalization

Status: reproduced the finite-center principalization for the displayed
top-left Case 2 source-coordinate chart map.

## Source Situation

In Aoyagi's displayed Case 2 chart the selected residual-block entry is
`d_(J+1,J+1)`. In the displayed source-coordinate chart map we write

```text
d_(J+1,J+1) = u,
```

and every other residual-block center coordinate as

```text
d_ij = u * d'_ij.
```

The finite center used here is only the residual-block coordinate set

```text
{(i,j) | J+1 <= i <= M(S), J+1 <= j <= M^(S+1)}.
```

Rows use the prefix minimum `M(S)`. Columns use the actual width
`M^(S+1)`.

## Reproduction

Let `C` be the finite residual-block center and let the displayed pivot be

```text
p0 = (J+1,J+1).
```

Under displayed continuation, `p0 in C`. Define the transformed finite-center
value function by

```text
F(p0) = u,
F(p)  = u * r_p,  p != p0.
```

Then the selected variable occurs in the transformed finite-center value set:

```text
u = F(p0).
```

Every transformed center value is divisible by `u`:

```text
F(p) = u * 1      if p = p0,
F(p) = u * r_p    if p != p0.
```

Therefore the ideal generated by all transformed finite-center values is
exactly the principal ideal generated by `u`.

The inclusion `span(F(C)) <= span(u)` follows from the displayed divisibility.
The reverse inclusion follows because `u = F(p0)` and `p0 in C`.

## Scope / Caveats

- This is finite residual-block center ideal algebra only.
- This uses Aoyagi's displayed top-left pivot `(J+1,J+1)`, not an arbitrary
  source pivot.
- The ideal is the finite center ideal generated by transformed residual-block
  center coordinates, not the loss/Kullback ideal or an analytic germ.
- Displayed pivot membership uses `1 <= S` and
  `J+1 <= prefixMinNat n (S+1)`.
- This does not prove chart production, atlas coverage, coordinate regularity,
  Jacobian or volume-form exponents, normal crossings, RLCT extraction,
  termination, a transition invariant, or repair of the printed Case 2 vector
