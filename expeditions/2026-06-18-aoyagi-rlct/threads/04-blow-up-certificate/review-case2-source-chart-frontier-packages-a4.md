Review mode: xhigh Lean API scout, xhigh hardener, and controller integration.

## Verdict

Accepted at the fielded implication scope.

The package does not use a selected frontier witness to choose terminal
conclusions.  Instead, each branch consequence remains an implication from its
own explicit hypothesis.

## Checks

- `SourceChartFrontierBoundaryPackages.frontierBranch` records only finite
  branch-domain bookkeeping.
- `continuing` calls the existing source-following next same-stage package and
  records next-center nonemptiness.
- `actualWidthStopped` calls the existing actual-width supplied-following
  finite-center package; it is the only stopped field with `(S+1,0)` relabelled
  level/exponent certificates.
- `rowExhaustedStopped` calls the existing terminal-last transported-prefix
  finite-center package; it does not identify the transported pivot row with an
  original row and does not relabel the state.

## Residual Risk

This is an assembly interface, not new source production.  Future uses must
still supply the relevant branch hypothesis and must not treat the package as
an atlas, chart-transition, or normal-crossing certificate.
