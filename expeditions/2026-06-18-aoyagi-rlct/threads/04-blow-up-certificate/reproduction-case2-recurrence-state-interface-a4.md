# A4 Case 2 Recurrence-State Interface

Status: reproduced the narrow recurrence-state interface needed after the
introduced-label finite-domain bridge.

## Source Data

Aoyagi's inductive state records:

```text
b_0 = 1,
b_i = (product over active labels with tilde_t_(s,k)=i-1 of u_(s,k)) * b_(i-1).
```

The active labels are the exceptional variables already introduced at state
`(S,J)`: earlier layers `s<S` with actual-width ranges, and current-layer
labels through `k<=J`. The displayed residual rows are `J+1..M(S)`, while the
residual columns use the actual width `J+1..M^(S+1)`.

Case 2 assumes no active label has `tilde_t` in `J+1..M(S)-1`. This makes the
recurrence factors on that interval equal to `1`, so the residual row weights
are flat.

## Interface Reproduction

The interface should not prove the transition invariant. It only names the
recurrence data that later transition proofs must supply:

```text
level(s,k) : Nat       -- source tilde_t_(s,k)
var(s,k)   : alpha     -- source variable u_(s,k)
step(r)    = product over introduced labels with level=r of var
weight(i)  = monomialRec step i
```

A separate Case 2 gap predicate says every introduced label avoids
`J+1 <= level < mu_S`.

The existing certificate layer uses integer least values. It can feed this
Nat-valued recurrence gap only through the explicit equality-only bridge

```text
leastValue(s,k) = level(s,k)
```

on introduced labels, plus an integer least-value gap. The stronger level/tail
package used by Case 1 extends this equality bridge with flat-tail assumptions,
but the Case 2 gap conversion does not need those flat-tail fields.

## Scope

This interface removes repeated ad hoc assumptions about `level`, `var`, and
row weights. It still assumes:

- the `level` map is Aoyagi's current `tilde_t`,
- the `var` map is the current source variable assignment,
- the Case 2 gap holds,
- row weights are generated by `monomialRec step`.

It does not prove the recursive invariant, source comparability, printed-vector
repair, arbitrary-pivot chart coverage, chart regularity/Jacobian, exponent
updates, termination, normal crossings, or RLCT extraction.
