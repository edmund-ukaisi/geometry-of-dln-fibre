## Statement

Lean now packages the introduced-label recurrence data used by the Case 2
row-weight bridge. The structure stores only `level` and `var`; the recurrence
factor `step`, row weight `weight`, and displayed residual-row weight are
derived from `introducedLabelFinset`.

The package includes a Case 2 gap predicate and proves that, under this gap, the
gap recurrence factors are `1`, displayed residual-row weights are flat, and the
displayed source-substitution `Q/P` theorem applies.

## Source role

Aoyagi's recurrence state uses active introduced variables `u_(s,k)` and their
levels `tilde_t_(s,k)` to define the diagonal row weights `b_i`. This checkpoint
names that recurrence interface so later transition work can state one clear
assumption instead of repeatedly passing `level`, `var`, and row-weight
expressions.

## Proved

- The recurrence step and row weights are derived from the finite
  introduced-label domain.
- An integer least-value gap converts to the Nat-valued recurrence gap when
  `leastValue = level` is supplied by `IntroducedLabelLevelInvariants`; the
  stronger `IntroducedLabelLevelTailInvariants` extends this equality-only
  package for Case 1 tail work.
- A packaged Case 2 gap makes gap recurrence factors equal to `1`.
- Displayed Case 2 residual-row weights generated by the package are flat.
- The displayed Case 2 source-substitution `Q/P` wrapper applies to the packaged
  recurrence state.

## Assumed

- The package's `level` map is Aoyagi's current `tilde_t`.
- The package's `var` map is the current source variable assignment.
- The Case 2 gap holds when the gap theorems are used.
- Row weights are generated by the package recurrence.
