<facts>
Setup. Fix an integer n >= 2. P, Z are generic n x n matrices; Y = P*Z is their product.
For an integer k with 1 <= k <= n, let V_k = { (P,Z) : rank(P*Z) <= n - k } (the "product-corank-k"
locus inside the 2*n^2-dimensional space of pairs (P,Z)).

Define the integer program minAdm on tuples of positive integers by:
  minAdm((a,)) = 0
  minAdm((a,b)) = a*b
  minAdm(M) = min over t in 0..min(M[0],M[1]) of [ (M[0]-t)*(M[1]-t) + minAdm( (t,) + M[2:] ) ]   (len(M) >= 3)
So e.g. minAdm((n,n,n,n)) is the arity-4 square value.

Define C_k = k^2 - floor(k^2 / 4).
</facts>
