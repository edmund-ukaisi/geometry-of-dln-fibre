**Verdict**

INFERENCE: **No.** A threshold-only invariant `(widths, row-weight multiplicities, branch)` does not determine the RLCT of the coupled residual. It forgets which divisor variables are the same, which are independent, and how a matrix block shares hidden columns. Those data change the Newton polyhedron, hence change the RLCT.

FACT: For a monomial residual ideal generated by monomials \(z^{\alpha_k}\), the RLCT of \(\sum_k |z^{\alpha_k}|^2\) is computed by
\[
\min \sum_i u_i
\quad\text{s.t.}\quad
u_i\ge 0,\ \langle u,\alpha_k\rangle\ge \tfrac12 \text{ for all }k.
\]

**Smallest Obstruction**

FACT: Two weighted-row residuals with the same coarse row data already differ:
\[
I_{\rm shared}=(\delta x,\delta y),\qquad
I_{\rm indep}=(\delta_1 x,\delta_2 y).
\]
Both look like “two rows, one column, each row has one weight” if weight identities are forgotten.

FACT:
\[
\operatorname{RLCT}(I_{\rm shared})=\tfrac12
\]
because the constraints are \(u_\delta+u_x\ge\tfrac12\), \(u_\delta+u_y\ge\tfrac12\), minimized by \(u_\delta=\tfrac12\).

FACT:
\[
\operatorname{RLCT}(I_{\rm indep})=1
\]
because the constraints split as \(u_{\delta_1}+u_x\ge\tfrac12\), \(u_{\delta_2}+u_y\ge\tfrac12\).

INFERENCE: The identity/equality relation among divisor variables is irreducible. Integer row weights lose it.

**Matrix-Block Obstruction**

FACT: The smallest genuine \(\Delta\)-matrix obstruction is \(2\times2\). Compare
\[
I_\Delta=\langle \Delta R\rangle,\qquad
\Delta,R\in{\rm Mat}_{2\times2},
\]
with the diagonal row-weight model
\[
I_{\rm diag}=\langle \operatorname{diag}(\delta_1,\delta_2)R\rangle.
\]
The LIGHT invariant identifies both as widths \((2,2,2)\), two output rows of weight \(1\), and the same rank-one branch \(t=(1,0)\).

FACT: \(I_{\rm diag}\) is the monomial ideal
\[
(\delta_1 r_{11},\delta_1 r_{12},\delta_2 r_{21},\delta_2 r_{22}),
\]
so its Newton LP is two copies of \((\delta x,\delta y)\), hence
\[
\operatorname{RLCT}(I_{\rm diag})=1.
\]

FACT: For \(I_\Delta\), blow up \(R=0\). The radial divisor has ratio \(4/2=2\). On the rank-two chart, right multiplication by \(\bar R\) is invertible, so the residual is four independent linear \(\Delta\)-coordinates, RLCT \(=2\).

FACT: On a rank-one chart
\[
\bar R=\begin{pmatrix}1&u\\ v&uv+\epsilon\end{pmatrix},
\]
a row \((p,q)\) of \(\Delta\) satisfies
\[
(p,q)\bar R=(A,Au+\epsilon B),\qquad A=p+qv,\ B=q.
\]
For two rows, the residual ideal is
\[
(A_1,A_2,\epsilon B_1,\epsilon B_2).
\]
The linear generators \(A_1,A_2\) contribute \(1\), and the monomial part \((\epsilon B_1,\epsilon B_2)\) contributes \(1/2\). Thus
\[
\operatorname{RLCT}(I_\Delta)=\min(2,2,3/2)=3/2.
\]

INFERENCE: Same LIGHT data, different exact RLCTs: \(1\) versus \(3/2\). The full matrix structure of \(\Delta\) binds.

**What Must Be Carried**

INFERENCE: Numeric unit coefficients need not be carried; analytic row/column unit changes preserve the ideal. But the invariant must carry at least the `diag(b)`-like symbolic data: the actual monomial exponent vector attached to each generator/row block, plus the incidence data saying which rows and hidden columns share the same variables. Equivalently, carry the weighted matrix/block support up to unit equivalence, not just total row degrees.

**Corank \(\ge 2\)**

FACT: The \(2\times2\) example is exactly the corank-\(\ge2\) issue. A full matrix block \(\Delta R\) is not equivalent to independent per-row scalars. The rank-one chart creates clean \(A_i\) generators and common \(\epsilon B_i\) generators; a row multiset cannot predict that.

INFERENCE: A per-row multiset does not capture a genuine \(\Delta\)-block.

**Depth \(L\ge4\)**

FACT: Appending shared deep layers does not remove the obstruction. On a radial blow-up of an appended \(2\times2\) layer \(C=0\), the full-rank chart has \(C=\rho\bar C\) with \(\bar C\) invertible, so right multiplication by \(\bar C\) is a unit change and the old residual reappears, with an extra radial candidate \(4/2=2\).

INFERENCE: Since the separating thresholds above are \(1\) and \(3/2\), both below \(2\), the shared-layer cascade cannot collapse the data to row multiplicities. The cascade keeps producing shared determinant/divisor variables whose identities enter the Newton LP. Thus the HEAVY `diag(b)`/matrix-incidence invariant is required for a faithful recursive resolution.
