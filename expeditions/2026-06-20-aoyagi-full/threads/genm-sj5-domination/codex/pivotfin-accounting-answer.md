1. SOUND

- [FACT] The pivot normal space has dimension \(u\rho=6\): \(\int_0^\varepsilon r^{5-2c'}dr<\infty\iff c'<3\).
- [INFERENCE] Thus \(C_{\rm ang}=\infty\) for \(3<c'<3.5\); extracting it at full exponent discards the effective \(ab/2=1/2\) corank gain.

2. SOUND

- [FACT] Even at fixed \((z,A_{\rm cor})\), the displayed map is not literally linear because of \(CP^{-1}B_{12}Q_b\).
- [FACT] After the shear \(\Gamma'=\Gamma+CP^{-1}B_{12}\), the generic fixed-outer map has rank \(3\operatorname{rank}(Q)=9\), threshold \(9/2\).
- [INFERENCE] Rank \(7\) arises from a rank-\(6\) outer-degenerate stratum plus one transverse direction; no fixed-outer linear-image rank gives \(7\).

3. SOUND

- [FACT] Compactness gives \(\|Q_b\|\le M\) uniformly, hence \(|\Gamma|\le \sqrt D/M\) implies \(\|\Gamma Q_b\|^2\le D\), so \(\mu\gtrsim D^{ab/2}=D^{1/2}\).
- [FACT] Vanishing \(\sigma_{\max}(Q_b)\) only enlarges this sublevel set; no lower singular-value bound is needed.
- [INFERENCE] On a positive-measure \(z\)-set with \(\|Q_p\|\asymp1\), the lower bound is \(\int_0 v^{6-2c'}dv\), divergent exactly for \(c'\ge7/2\).

4. CONDITIONAL

- [FACT] On transverse fixed-outer charts, the available dimension is \(u\rho+au=6+2=8\), giving cutoff \(c'<4\).
- [FACT] For the anchor, \(7/2<4\), so the exponent arithmetic permits the DROP.
- [INFERENCE] Uniformity near degenerating \(Q_p,Q_b\) does not follow from a.e. rank; it requires a separate uniform angular/Jacobian ratio lemma.
- [FACT] If \(b>u\), then \(au<ab\), leaving the failure window \((u\rho+au)/2<c'<(u\rho+ab)/2\). Thus \(b\le u\) is necessary, not sufficient.

5. Threshold sandwich

- [FACT] New sublemma: the uniform corner-volume estimate in (3).
- [INFERENCE] It gives \(\mathrm{RHS}<\infty\Rightarrow c'<7/2\).
- [FACT] Invoke the stated full-chain threshold \(c'<7/2\Rightarrow\mathrm{LHS}<\infty\).
- [INFERENCE] This covers \(3<c'<3.5\); if both threshold equivalences are already admissible, no genuinely new lemma is needed.
