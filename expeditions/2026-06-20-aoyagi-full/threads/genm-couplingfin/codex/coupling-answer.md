### Q1

[FACT] \(c_{\mathrm{free}}=+\infty\), not \(5/2\) or \(3\). Indeed,
\(\operatorname{rank}(Pz_0)=2\) while \(\operatorname{rank}(B_{12}A_{\rm cor})\le1\), so \(w\neq0\).

[FACT] Without \(|\det P|>0\), the excluded stratum \(A_{\rm cor}\in\operatorname{row}(z_0)\), \(P=-B_{12}\alpha\), has codimension \(5\) in dimension \(9\), hence threshold \(5/2\). It consists entirely of singular \(P\). Thus the fixed-\(Q\) rank \(6\) claim is true, but its threshold \(3\) is false on the stated pivot chart because its kernel misses the chart.

### Q2

[FACT] \(c_{\mathrm{shell}}=+\infty\), whereas \(u\rho/2=3\). On the shell,
\[
w=\|[P\mid B_{12}]Z_{\rm full}\|_F^2
 \ge \varepsilon^2\|[P\mid B_{12}]\|_F^2>0.
\]
The shell is therefore unnecessary here; \(J_{\rm free}\) and \(J_{\rm shell}\) have the same infinite threshold.

[FACT] Generally, \(u\rho/2\) applies only when the coefficient kernel meets the \(P\)-invertible chart; generically this requires \(M_1-\rho\ge u\), equivalently \(\rho\le b\).

### Q3

[FACT] As \(A_{\rm cor}\to0\),
\[
w\longrightarrow\|Pz_0\|_F^2
 \ge \sigma_{\min}(z_0)^2\|P\|_F^2>0.
\]
Thus \(\{w=0\}\) is disjoint from \(\{Q_b=0\}\); this direction creates only a separate corank charge, not pivot divergence.

### Q4

[FACT] Put \(m=\minAdm(u,M_2,\ldots)\). If the shell coefficient-kernel is nonempty, the exponent condition is \(m\le u\rho\); if it is empty—generically whenever \(\rho>b\)—the condition is automatic.

[FACT] For \((3,3,3)@2\): \(\rho=3>b=1\), \(m=5\), so \(c<5/2\) is controlled. For \((3,3,4,4)@2\): \(\rho=3>b=1\), \(m=7\), so even \(c<7/2\) is controlled despite \(u\rho=6<7\). Neither case is marginal. When \(m=u\rho\) and the kernel is present, finiteness is assured only for strict \(c<m/2\); endpoint/uniform constants require pole-order information.

### Q5

[INFERENCE] There is no uncontrolled direction in either requested cut. The apparent \(5/2\) stratum violates \(|\det P|>0\), while the shell removes rank-drop independently. A genuine wall occurs only when the shell coefficient-kernel is nonempty and \(m>u\rho\); that maximal-rank kernel direction is removed by neither the shell nor a corank charge.
