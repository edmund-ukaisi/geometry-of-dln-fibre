VERDICT: **hS1' is FALSE**.

For the reads term,
```lean
(reindex eR eCpiv Reads) i j
= Reads ((rThresholdSplit r a) i) ((pivotThresholdSplit r b J) j)
```
So if `pivotThresholdSplit r b J j = inl q`, column `j` is the `q`-th pivot column, but the read block `inl q` decodes to threshold column `q` of `Mdev`. If `pivotThresholdSplit r b J j = inr q`, column `j` is the `q`-th non-pivot column, but `readY/coreRead` at `inr q` decodes to threshold column `r + q` of `Mdev`.

Thus the reads term is
```lean
Rreads i j = Mdev i ((rThresholdSplit r b).symm ((pivotThresholdSplit r b J) j))
```
not `Mdev i j` unless the pivot split equals the threshold split. The corner term is calibrated by `hcorner` to give `deepest_last * Qf_last`; the reads term is placed by the pivot split while decoding threshold columns. Those are not the same column semantics.

Small concrete counterexample, smallest with `readY` and `coreRead` both present:

- `r = 1`, `a = 2`, `b = 2`
- `J 0 = 1`, so the pivot column is column `1`, not column `0`
- Let
  ```text
  Mdev = [ x  y
           z  t ]
  ```
Then pivot column order is `[1]`, non-pivot order is `[0]`. Hence the reindexed reads term is
```text
[ y  x
  t  z ]
```
because `readY/coreRead`, which decode threshold column `1`, are placed into actual non-pivot column `0`. The target deviation term is still
```text
[ x  y
  z  t ]
```
So with, for example, `Qf_last = I`, generic `Mdev` gives `F_last != (deepest_last + Mdev) * Qf_last`.

The correct statement is:
```lean
F_last =
  deepest_last * Qf_last
  + (colPerm_J Mdev) * Qf_last
```
with
```lean
(colPerm_J Mdev) i j =
  Mdev i ((rThresholdSplit r b).symm ((pivotThresholdSplit r b J) j))
```
and, with `Pf_last` retained in the displayed reconstruction shape,
```lean
F_last =
  deepest_last * Qf_last
  + Pf_last * (colPerm_J Mdev) * Qf_last
```

Computed fact: the displayed index formula for the reads term follows directly from the given `reindex` definition and the two split facts.  
Inference: the theorem as stated is false for arbitrary fixed `J`; it becomes true in the special case `J = castLE` or in degenerate cases where the column permutation is killed after right multiplication by `Qf_last`.
