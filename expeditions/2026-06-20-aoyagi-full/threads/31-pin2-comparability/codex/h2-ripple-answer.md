**FACT**

The general “thin set” claim is **false as an analytic principle**.

If `f` and `g` are genuinely equal a.e. as measurable functions, then the integrals defining the RLCT are equal; changing values on a measure-zero set does not matter, even if that set lies in `{f=0}`. But if `f,g` are real-analytic and agree off a proper analytic subset, then they agree as analytic germs. So any nontrivial replacement by another analytic formula is not just a value-change on a null set; it changes the analytic germ/ideal near that set.

The precise invariant condition is valuative: on a common log resolution, if

```text
f ∘ π ~ unit * ∏ y_i^{N_i},     Jac(π) ~ unit * ∏ y_i^{ν_i-1},
```

then `rlct(f) = min_i ν_i / N_i`, with the usual real-locus caveat. For sums of squares, use the ideal generated by the summands. RLCT is the first non-integrability exponent of `f^{-s}`, and resolution/log-principalization is the standard way to read the pole data. ([arxiv.org](https://arxiv.org/abs/0707.2308))

So if `g = f + q ≥ f`, then `rlct(g) ≥ rlct(f)`. Equality holds exactly when at least one divisor computing `rlct(f)` has the **same vanishing order** for `g` as for `f`; equivalently, the added term/removed zero-set does not affect any RLCT-computing valuation. “Higher codimension” is only a heuristic; the real condition is “does not touch the leading pole divisors.”

**INFERENCE**

For your `Score` versus `coreΦ`, I would not justify equality by saying the tilted-kernel locus is measure-zero. That is the wrong reason.

The structural reason is stronger:

```text
Score   = || S0 (I - K) S1 ||_F^2
coreΦ   = || S0 S1 ||_F^2
K(0) = 0, hence W := I - K is an analytic GL_M-valued unit near 0.
```

In product-regular coordinates where `E` denotes the full `Sreg` residuals,

```text
F(E,θ,S0,S1) = ||E||^2 + ||S0 W(E,θ) S1||^2
G(E,θ,S0,S1) = ||E||^2 + ||S0 S1||^2.
```

The triangular map

```text
Ψ(E,θ,S0,S1) = (E,θ,S0,W(E,θ)S1)
```

is an analytic local diffeomorphism with derivative identity at `0`, and

```text
G ∘ Ψ = F.
```

Therefore

```text
rlctAtOn(Sreg + Score) = rlctAtOn(Sreg + coreΦ)
```

provided the `AtOn` domain is also identified locally by this diffeomorphism, or you are working on an open chart neighborhood.

On codimension: in the `(2,3,2), r=1, M=2` scalar-core case, after `Sreg=0`, the score-fibre equation is one scalar bilinear equation

```text
S0 (I-K) S1 = 0.
```

The tilted part with `S0S1 ≠ 0` is not high codimension inside that fibre; for fixed small nonzero `K`, it is relatively open in the score-zero hypersurface. In the full ambient chart it has the same expected codimension as the loss fibre: `nReg + 1`, i.e. `3 + 1 = 4` in the `(2,3,2)` anchor. Within the fibre its codimension is `0`. For `(2,2,2)`, `M=1`, `I-K` is a scalar unit, so the tilted cancellation cannot occur and the zero loci already match.

So the numerical agreement is not evidence that a measure-zero locus is harmless. It is evidence for the analytic-unit change of variables above.

**Bottom Line**

The false transfer

```text
loss ≍ Sreg + coreΦ
```

must not be used.

The headline is **safe** if rebuilt as:

```text
loss ≍ Sreg + Score
rlct(Sreg + Score) = rlct(Sreg + coreΦ)   via S1 ↦ (I-K)S1
rlct(Sreg + coreΦ) = nReg/2 + rlct(reduced-chain core)   via R1
```

The tilted-kernel locus is a genuine pointwise comparability hazard, but not an RLCT hazard once the `Score → coreΦ` step is proved by analytic diffeomorphism/unit equivalence rather than by two-sided pointwise comparability or “thin set” reasoning.
