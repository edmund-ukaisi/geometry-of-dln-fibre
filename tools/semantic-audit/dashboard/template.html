Work Packets

Work packets are the actionable queue produced by the deterministic audit run. A packet becomes durable audit memory only after an answer is appended to the corresponding records JSONL file and the pipeline is rerun.

open: ready for semantic work stale: answered before the current context blocked: waiting on prerequisite records answered: backed by a durable record answer text renders TeX math default sort: next best packet first
