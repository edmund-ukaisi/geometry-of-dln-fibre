Where the lines went snapshot CSV · H

Left — three measures of the same tree, per 6-hour snapshot: raw Lean (physical lines), native-token Lean (lines carrying code after Lean's own comment/doc parsers strip prose — the honest proof-mass proxy, ~0.65 of raw), and expedition prose (the ledger, certs, cards). Snapshot-based = immune to re-land double-counting, unlike diff arithmetic. Right — gross churn per bucket: added vs deleted Lean. The deletion band staying thin (~7% lifetime) is the receipt for "thrash lived in design, not shipped code".

Expedition pulse commits.json · H

Commits per day: build (feat/fix/refactor), coordination (ledger/docs/ticks — the controller's shared-memory writes), other (merges, wip). Coordination dominating is the price of a 3-week multi-agent proof staying coherent; the ratio chart next to it is that price as a curve — 1.7 prose lines per Lean line lifetime, climbing to ~4:1 in adjudication-heavy endgame days. That climb is the burden-of-knowledge effect, measured.

The error economy events.json flags · H (keyword-grade)

Ledger blocks per day carrying correction-class keywords (corrected / retracted / refuted / WALL) vs blocks recording landings. Keyword-grade: a block discussing corrections counts once; event-grade classification is the planned S pass. The table lists the longest-lived corrected claims among pairs where the correction names its target — median catch latency in that subsample is under an hour, biased fast by construction (quick self-corrections cite targets; long sagas often don't).

Knowledge debt knowledge_debt.md · H⁻

"Found already banked": a theorem the expedition needed, already proven in its own tree, unfound. Debt hours = time the artifact sat banked before a lane physically rediscovered it. The double-mnp rows are the sharpest datum in the retro — the same theorem independently rediscovered twice, ~11h apart, by different lanes: the index failure repeating after it had already been exposed. This table is the empirical case for the librarian role.
